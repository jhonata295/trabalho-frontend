# FutManager

Sistema de Gestão de Times de Futebol desenvolvido em React.

## Tecnologias

- React
- React Router DOM
- Context API
- Axios
- CSS

## Funcionalidades

- Cadastro de Times
- Listagem Dinâmica
- Busca
- Integração com API
- Estado Compartilhado

## Como executar

npm install

npm run dev
