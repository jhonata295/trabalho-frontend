# ⚽ FutManager - Sistema de Gestão de Times de Futebol

Aplicação desenvolvida em React para gerenciamento de times de futebol, permitindo cadastro de equipes, visualização de dados cadastrados, pesquisa de times e integração com API REST.

---

## 🚀 Ambiente de Desenvolvimento

### 🛠️ Tecnologias Utilizadas

| Tecnologia       | Função                                |
| ---------------- | ------------------------------------- |
| React            | Construção da interface               |
| React Router DOM | Navegação entre páginas               |
| Context API      | Gerenciamento de estado compartilhado |
| Axios            | Consumo de API REST                   |
| CSS3             | Estilização e responsividade          |
| Vite             | Ambiente de desenvolvimento           |

## ▶️ Como Executar o Projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/jhonata295/trabalho-frontend.git
```

### 2. Entrar na pasta

```bash
cd trabalho-frontend
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o projeto

```bash
npm run dev
```

### 5. Abrir no navegador

```bash
http://localhost:5173
```
